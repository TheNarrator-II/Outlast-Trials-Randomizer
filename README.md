# Outlast-Trials-Randomizer
A bare bones loadout randomizer for Outlast Trials randomizing rigs, amps and impostor amps. Written in C. Inspired by otrandomizer written by PaulCotton42

# Installation Guide
1. run *https://github.com/TheNarrator-II/Outlast-Trials-Randomizer* in the terminal. This will create a directory within the directory you typed the command in with the randomizer, the code file and the README. If you only want the randomizer, click on the randomizer.c file --> raw --> download file.
2. run *gcc -o "whatever you want to name the randomizer" randomizer.c*
3. run *./randomizer* to use it. The results will be displayed straight into the terminal.
4. Happy outlasting :)
